🚨 Critical Issues

1. Unencrypted Token Storage in SharedPreferences

CRITICAL
Location: storage_service.dart (line 12, 18)

Issue:

  • JWT tokens are stored in plaintext in SharedPreferences
  • SharedPreferences is not encrypted by default on Android/iOS
  • On Android, data is stored in `/data/data/app_name/shared_prefs/` accessible to malware or device compromise
  • Attackers with device access can extract authentication tokens

Impact: Complete account compromise, token reuse, OWASP Mobile Top 10: A2 - Insecure Data Storage

✅ Recommendation:

Replace SharedPreferences with encrypted storage using flutter_secure_storage package:

import 'package:flutter_secure_storage/flutter_secure_storage.dart'; class StorageService { static const _storage = FlutterSecureStorage(); static Future<void> saveToken(String token) async { await _storage.write(key: 'auth_token', value: token); } static Future<String?> getToken() async { return await _storage.read(key: 'auth_token'); } }

Add to pubspec.yaml:

dependencies: flutter_secure_storage: ^9.1.0
